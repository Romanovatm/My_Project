# Разработка виджета банковских операций

## Описание:

Разработка виджета банковских операций - это проект для создания серверной части виджета банковских операций в учебных целях.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Romanovatm/My_Project.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

1. Функция для маскировки номера банковской карты```def get_mask_card_number(card_number)```

Пример вызова:```print(get_mask_card_number("1234567890123456"))```

Пример вывода: "1234 56** **** 3456"

2. Функция для маскировки номера банковского счета```def get_mask_account(account_number)```

Пример вызова:```print(get_mask_account("12345678901234560000"))```

Пример вывода: "**0000"

3. Функция для маскировки данных банковской карты, исходя из ее типа, номера или счета```def mask_account_card(card_data)```

Пример вызова:```print(mask_account_card("Visa Platinum 1234567890123456")```

Пример вывода: "Visa Platinum 1234 56** **** 3456"

Пример вызова:```print(mask_account_card("MasterCard 1234567890123456")```

Пример вывода: "MasterCard 1234 56** **** 3456"

Пример вызова:```print(mask_account_card("Счет 12345678901234560000")```

Пример вывода: "Счет **0000"

4. Функция, для форматирования даты из 'ISO 8601' в 'ДД.ММ.ГГГГ'```def get_date(date_iso_format)```

Пример вызова:```print(get_date(2024-03-11T02:26:18.671407))```

Пример вывода: "11.03.2024"

5. Функция для сортировки списка словарей по состоянию транзакций```def filter_by_state(information, state="EXECUTED")```

Пример вызова:```print(filter_by_state([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
                                        {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'}, 
                                        {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
                                        {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}, "CANCELED"]))```

Пример вывода: [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'}, 
                {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}]

6. Функция для отсортировки списка транзакций по дате```def sort_by_date(information, is_reversed=True)```

Пример вызова:```print(sort_by_date([{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
                                     {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},

Пример вывода:[{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'}, 
               {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'},
